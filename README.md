# Jesse Barnabs: Portfolio Website

A personal portfolio website built with HTML and CSS for Assignment 2: Portfolio Website (HTML & CSS).

## About this project
This is my portfolio. I kept the same content and structure and added CSS styling, a responsive layout, and simple interactions.

## Files
- `index.html`: the page content (header, navigation, About, Projects, Contact and footer)
- `style.css`: the colours, fonts, spacing, layout and effects

## CSS features used
- **Flexbox** to lay out the navigation links in a row
- **CSS Grid** to arrange the project cards in three columns
- **Media query** (screens 700px wide or smaller) so the nav and cards stack on phones
- **:hover and :focus** effects on the links and project cards
- **Transitions** for smooth colour changes and card movement
- **Animation** (a fade-in on the header when the page loads)

## Projects shown on the site
1. PostgreSQL Database (built in pgAdmin 4)
2. Bank Account System (Python, classes and objects)
3. Campus Lost and Found System (currently at the proposal stage)

## How to view it
Download `index.html` and `style.css`, keep them in the same folder, and open `index.html` in a web browser.
